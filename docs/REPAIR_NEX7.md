# NEX-7 维修说明（给维修店技术人员）

机型：Sony NEX-7（ILCE-7 之前的 APS-C 旗舰），序列号 <serial>，原厂固件 1.03。
故障：开机全黑、无画面、无指示灯、USB 不识别。

---

## 一、结论：不是硬件坏，是启动配置被写坏

相机内核正常、驱动正常，但**应用（/usr/bin/sen.elf）没有启动**。
原因：`/setting/mode/dmode` 这个文件被写成了单字节 `x`（0x78）。
系统按它的**首字符**决定要不要启动应用，`x` 不是合法值（合法值是 `0`/`1`/`2`/`3` 开头），
所以应用不启动 → 没有界面、没有灯、没有 USB 服务。

**固件本身完好**（/system、/usr 都不用动），**不需要换主板**。

## 二、最小改动（推荐做法 A，只改 1 个字节）

把 `/setting/mode/dmode` 的内容改成 **`3` + 换行**：

| 项 | 值 |
|---|---|
| 文件 | `/setting/mode/dmode` |
| 原内容 | `78`（1 字节，字符 `x`） |
| 改成 | `33 0A`（2 字节，字符 `3` + 换行） |
| 目录项里的文件长度 | 由 1 改成 2 |

同时**删除**这两个文件（是我们误放进去的）：

- `/setting/env.txt`（30 字节）
- `/setting/ldtest.so`（158,988 字节）

`/setting` 里的其它文件（`Backup.bin`、`DmmConfig.bin`、`facedmy.bin`、`kemco.txt`、`ulogio.bin`、`.hasp`、`appfw_infra`、`gps`、`mode`、`updater`）**全部保留**，
它们是本机的逐机校准数据，删了会掉画质/坏点校正。

## 三、硬件参数（拆机 / 编程器需要）

| 项 | 值 |
|---|---|
| 存储芯片 | Toshiba **TC58NVG0S3ETA00**，TSOP48，128 MiB（SLC NAND） |
| 页 / 备用区 | 2048 + 64 字节 |
| 擦除块 | 128 KB（0x20000），共 1024 块 |
| **`/setting` 分区** | 起始 **0x420000**，长度 **0x280000**（2.5 MB），即**擦除块 33–52** |
| 文件系统 | vfat（簇 16 KB） |
| 引导区 | 块 0（0x0–0x20000），**不要动** |
| /system /usr | 分别从 0x6A0000、0x52A0000 开始，**不要动** |

> 如果芯片读出来和上表对不上（例如前面有坏块），先验证 `0x420000` 处是不是一个 vfat
> 引导扇区（0x36 处为 `FAT12   ` 或 `FAT16   `，第 510 字节为 `55 AA`），
> 再按实际偏移修正，不要盲改。

## 四、三种做法，按易到难

### 做法 A：有串口（最简单）
主板上 `ttyAM0` 的调试焊盘（3.3V TTL，115200 / 38400 8N1，GND 与屏蔽罩通）接 USB-TTL，
开机会给一个 root shell，然后：

```sh
mount -t vfat /dev/nflasha2 /setting
echo 3 > /setting/mode/dmode
rm -f /setting/env.txt /setting/ldtest.so
sync
```

### 做法 B：有 NAND 编程器
0. **必须拆焊**（热风枪取下芯片）。夹子在线读取在这个板上不可靠：48 脚 0.5mm 间距难压准，
   且断电时 SoC 会经 ESD 二极管给总线倒灌，读出的数据可能出现位翻转——对"改一个字节"来说是致命的。
1. 拆下芯片，**完整读两遍**，两份 CRC 必须一致，保留原始 dump（写坏了要能原样写回）；
2. 只改 `0x420000 + 0x280000` 范围内的那一处（用我们提供的 `setting_patch.py` 可直接生成修好的镜像）；
3. 写回时**必须重算 ECC/备用区**（或用编程器的芯片 ECC 引擎），否则该页会校验失败；
4. 写回后读回比对，再装回上机。

### 做法 C：以上都做不了
换同型号主板（淘宝约 ¥300–600）。换板后本机校准数据会变，属于次选。

## 五、请不要做

1. **不要重刷固件**。固件是好的；重刷有可能把「升级模式」也弄坏，更难救。
2. **不要整块擦除或格式化 `/setting`**，里面是逐机校准数据。
3. **不要逐字节改 NAND 而不重算 ECC**。
4. 不要动块 0（引导区）以及 `/system`、`/usr` 两个分区。

## 六、修好后的验收

1. 开机有画面、有灯，能进菜单；
2. 插 USB 电脑能识别为相机（海量存储）；
3. 拍一张 JPEG，回放正常（说明 /setting 的校准数据还在）。
