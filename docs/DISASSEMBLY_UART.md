# 拆机取串口（免焊优先版）

> 给你的方案：**你自己拆，我们尽量不焊。**
> 目标只有一个：把相机的 UART（ttyAM0）接出来，看到 shell，然后一条命令把 dmode 改回去。
> 这篇不需要你懂电路，只需要会拧螺丝、会拍照、会用万用表通断档。

---

## 0. 一句话结论

**能帮你省掉焊接的，是"测试点"这个事实**：很多板子在 SoC 旁边会留一排没焊元件的焊盘或过孔（工厂调试用的）。
只要那排里面有 GND 和 TX，你就可以用"插针 / 塞线 / 探针"接触，**一根都不用焊**。

如果拆开发现没有这种位置，我们再谈焊——那时候只需要焊**一根 TX**（GND 找螺丝孔或屏蔽罩，有大焊盘）。

## 2. 拆机（你负责的部分）

### 铁律
1. **先拔电池**，全程戴防静电手环（或先摸一下金属水管放电）。
2. **每拆一层拍一张照**，尤其是排线走向——装回去全靠这些照片。
3. 拔排线只捏**黑色/白色卡扣**，不要拽线；FPC 排线断一根就报废。
4. 螺丝按位置分格放（磁性垫或纸上画格子写位置）。
5. 拆到"能看到主板正面和背面"就停，**不要把主板从壳里拿出来**。

### 大致顺序（NEX-7 通用思路，具体以你拆的时候看到的为准）
1. 电池、SD 卡、镜头取下。
2. 底部螺丝 → 两侧螺丝 → 顶部（电源开关附近）螺丝。
3. **眼罩**（取景器橡胶）可以拔下来，下面常藏螺丝。
4. 手柄橡胶/皮饰下面也可能有螺丝——用手摸一圈，感觉有硬点就是。
5. 后盖是卡扣 + 双面胶：从底部缝隙插塑料撬棒，绕着走一圈，**不要用金属**。
6. 打开后先看到 LCD 排线、EVF 排线、按键板排线——**拍照，再拔**。
7. 目标：露出主板的**两面**，特别是 **SoC（最大的那颗 BGA）周围** 和**屏蔽罩边缘**。

### 拍照清单（拍完发我，我帮你在图上找测试点）
- [ ] 主板**正面**全景（清楚到能看清丝印文字）
- [ ] 主板**背面**全景
- [ ] SoC 周围**特写**（45° 斜一点，让焊盘反光）
- [ ] 任何**没焊元件的多针焊盘/过孔阵列**（3–4 个一排那种，最可疑）
- [ ] 丝印上有 `TP` / `J` / `CN` / `UART` / `DEBUG` 字样的地方
- [ ] 屏幕排线座、电池座附近的特写（有时调试口在边上）

> 拍照技巧：手机开闪光灯容易过曝，用**侧光**（台灯从侧面打）能让焊盘和丝印都清楚。

## 3. 找到 GND 和 TX（不用懂电路）

### 第 1 步：GND（这个一定能找到）
万用表打到**通断档（蜂鸣）**：
- 一表笔顶住**电池负极触点**（或任何裸露的金属屏蔽罩）；
- 另一表笔点候选焊盘，**响 = GND**。
- 屏蔽罩本身、螺丝孔周围的铜环，基本都是 GND。

### 第 2 步：TX（相机往外发数据）
万用表打到**直流电压档（20V 或 2V）**：
- 黑表笔接 GND，红表笔点候选焊盘；
- **装上电池、开机的那一瞬间**看读数：
  - 电压**跳一下**（在 0–3.3V 之间抖动）→ 很可能就是 TX；
  - 一直稳定 3.3V 或 0V → 不是 TX（3.3V 的那个是电源，**千万别接**）。
- 这一步最好两个人：一个负责开机，一个盯着表。一个人也行——把表笔用胶带固定，然后自己按开机。

### 第 3 步：确认
找到"开机瞬间会跳"的那个点，就是我们的目标。

## 4. 不焊怎么接上（三种方案，按成功率排）

### 方案 1：过孔塞线（成功率最高，且最稳）
如果 TX 测试点是一个**过孔**（中间有孔）：
1. 剪一段漆包线（3–5cm），用镊子把一头**从过孔里穿进去**；
2. 稍微折一下卡住，或用牙签、镊子把线压紧；
3. 用 Kapton 胶带把线压在板子上固定；
4. 另一端接 USB-TTL 的 RXD。

### 方案 2：探针/测试钩（不用买别的）
1. 弹簧探针（或缝衣针 + 杜邦线）针尖顶住焊盘；
2. **Kapton 胶带**把针身压在板上，形成一点压力；
3. 接 GND + RXD。
4. 缺点：一动就掉，成功看手感。试错成本 ¥20。

### 方案 3：夹子（只有在有引脚/排针时才用得上）
如果那块地方刚好有个**没焊的排针孔**，直接插一根 2.54mm 排针进去，摩擦力就够。

> **三种都是"只接 GND + TX（模块的 RXD）"，先只收不发。**
> USB-TTL 的 **VCC 一定不要接**——接错会烧板子。

## 5. 抓日志

1. 电脑装 CH340 驱动，插上模块，记下 COM 号；
2. 打开串口终端：`putty -serial COM3 -sercfg 115200,8,n,1,N`；
3. 装电池 → 开机；
4. 波特率按顺序试：**115200 → 38400 → 9600 → 57600**。

**看到什么算成功：**

| 现象 | 含义 |
|---|---|
| 出现 `Uncompressing Linux...` / `<<init start>>` / `insmod` | 通了，等它跑完 |
| 出现 `/ #` 或 `#` 提示符 | 成功拿到 root shell，直接进第 6 步 |
| 乱码但成规律 | 波特率不对，换一档 |
| 完全没反应 | 接线/焊点/TX 点的问题，不是相机死了 |

## 6. 拿到 shell 之后（照抄）

```sh
cat /setting/mode/dmode ; echo          # 现在应该是 x
mount | grep setting                    # 没挂就 mount -t vfat /dev/nflasha2 /setting
echo 3 > /setting/mode/dmode
rm -f /setting/env.txt /setting/ldtest.so
cat /setting/mode/dmode ; echo          # 确认变成 3
sync
reboot
```

## 7. 什么时候才轮到焊接

只有一种情况：**找了半天，TX 那个点是个 0.3mm 的裸焊盘，塞不进线、探针也压不住**。

那时候的方案（按难度递增）：
1. 只焊 **TX 一根线**（GND 找螺丝孔，不用焊）——这是最小焊接量；
2. 先在一张废板（旧路由、坏手机板）上练 30 分钟：能焊出"光亮、像小火山"的焊点、不连锡，就算可以；
3. 焊完用万用表通断档量一下：焊点和目标焊盘通、和旁边**不通**，才可以上电。

**不要**在没练过的情况下直接动相机板——焊盘掉了是不可逆的。
