# 拆机与 UART 定位现场记录（2026-11-17 暂停点）

## 已确认的事实

| 项 | 结论 | 依据 |
|---|---|---|
| 主板 | **SY-296**，就是主控板 | 传感器排线插在它上面；8 个 FPC 座 |
| 主 SoC | CXD4132（BIONZ，3× ARM11） | OpenMemories 硬件文档 + 内核自称 ARMv6 |
| SoC 位置 | **PoP**：三星 K5B2G4GQCM 封装叠在上面 | 板上找不到独立 ARM11 大芯片 |
| 存储 | NAND 在同一个 MCP 封装里 | 三星 K5 系列 = NAND+LPDDR2 复合封装 |
| 传感器板 | IS-095（丝印 "IS-095 DEC 2280"） | 拆到底后确认 |
| 东芝芯片 | TMP19A44FDAXBG = TX19A/H1 单片机（512KB Flash / 48KB RAM），**不是 ARM SoC** | 东芝数据手册 |

**后果**：NAND 是 BGA/MCP → 编程器读取路线**不可行**。只剩 UART。

## UART 定位进度

- 找到 2×2 焊盘阵列（Toshiba 芯片圆点旁，板底中央，二维码标记左侧）；
- **其中一个点对 GND 蜂鸣，读数≈0Ω** → 这是 GND；
- 另外三个点待测（推测 VCC / TX / RX）。

## 电源

- 主板上电源焊盘丝印 **R（红/正极）** 与 **B（黑/负极）**；
- 焊盘可能涂了绝缘层，通断测不出，但丝印足够判断极性；
- 红黑线原本连着**一个电容**，电容连着电池仓；
- 相机现在完全拆散，需重新建立供电：电池仓 + 铜丝压接，或焊接。

## 下一步（恢复时从这里继续）

1. 拍"电容 + 两根线 + 电池仓"，确认接法；
2. 量电压确认 +7.4V 与极性，红→R、黑→B；
3. 通电后测另外三个调试脚的电压（黑笔压橙色 GND 焊盘）：
   - 稳定 3.3V/1.8V → VCC（顺便确定电平）
   - 空闲高电平 + 轻微跳变 → TX/RX
4. CH340 只接 **GND + RX**（绝不接 VCC），115200 8N1，插电看有没有字符；
5. 没字符 → 换点、换波特率（38400/9600/57600）、接上传感器排线再试。
