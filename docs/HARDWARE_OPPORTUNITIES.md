# 硬件机会清单（拆机之后能做什么）

> 前提：**"读"零风险，"改"才有风险。** 拆开后绝大部分动作都应该是读和量。
> 顺序永远是：测绘 → 接只读 → 才谈改动。

---

## 一、拆开之后，这台机器的身份变了

从"一块砖"变成"唯一一台你能随便看、随便量的 NEX-7"。这个价值比修好它更大。

## 二、能解锁的东西（按价值排）

| 能力 | 怎么拿到 | 能换来什么 |
|---|---|---|
| **内核日志 + shell** | UART（ttyAM0） | 实验从"改完猜"变成"看它卡在哪" |
| **全芯片调试** | JTAG（若板上有空焊盘） | 读内存、改寄存器、不停机改存储 |
| **完整 NAND dump** | 升级模式 shell / 编程器 | 备份、对比、给社区（网上没有这台机器的 dump） |
| **ECC / OOB 布局** | 从 dump 反推 | 以后任何 NAND 都能安全改 |
| **/wbi 那 36MB** | dump nflasha5 | 从没打开过，可能藏着热启动/恢复机制 |
| **板级资料** | 拍清楚 + 标丝印 | 网上 NEX-7 只有"开后盖"级别的拆机图，板级是空白 |

## 三、实用的硬件改装（低风险优先）

1. **假电池 + 电流表**：从电池仓引 7.4V 稳压，串电流表。
   - 好处：长时实验不用换电池；**没有串口时靠电流曲线判断"启动到哪一步"**。
   - 必须：保险丝 + 防反接二极管 + 电压先量准。
2. **散热**：13 小时录像补丁发热大，加铜箔/导热垫。
3. **HDMI 直出**：研究 clean output（中风险）。
4. 镜头/传感器接口实验：没明确目标，高风险，先别碰。

## 四、用嘉立创做板的三个候选

> 现实约束：**我还没见过你的主板**，所以第一块板必须"不依赖尺寸"。
> 依赖具体位置的板子（假电池）要等拆开量过尺寸再做。

### 候选 A（推荐先做）：UART 探针转接板

**解决什么**：你现在要"用手把探针按在 0.5mm 焊盘上"，一动就掉；这块板把探针固定住，接杜邦线到 CH340。

| 项 | 规格 |
|---|---|
| 尺寸 | 25 × 20 mm，2 层，1.6mm，无贴片元件 |
| 连接 | 一侧 1×4 排针母座（2.54mm）插 CH340 的 GND/TXD/RXD |
| 探针 | 2–3 个 P100 系列弹簧探针焊盘（0.68mm 头），间距 2.54mm |
| 保护 | TX/RX 串 100Ω 电阻（可选，限流） |
| 指示 | 可选一个 3.3V LED + 1kΩ（确认供电在你这边） |
| 固定 | 四角留 M1.6 螺丝孔，方便用胶带/夹具压住 |
| 成本 | 5 片约 ¥10–30（嘉立创打样），探针约 ¥1/根 |

**为什么它值**：直接消灭"接触不良"这个最大的不确定性来源。探针压不住是新手最容易误判成"相机没输出"的原因。

### 候选 B（拆开量过尺寸再做）：NP-FW50 假电池 + 电流采样

- 板形按电池仓做（需要你量长宽厚、触点位置）；
- 输入 7.4–8.4V，串联 0.1Ω 采样电阻 + 保险丝 + 防反接；
- 可以接万用表测电流，或加 INA219 + 小屏。

**风险**：电压接错会烧主板。必须保险丝 + 防反接，第一次上电先用万用表量输出。

### 候选 C（可选）：通用测试点引出板

- 一块小板上有 0.5 / 1.0 / 1.27 / 2.54mm 四种间距的焊盘阵列；
- 配探针，能压在任何板子上取信号；
- 通用性强，但优先级低于 A（A 已经覆盖主要场景）。

### 不建议做的

- **TSOP48 转接座**：市售 ¥30–60，自制不划算；
- **逻辑分析仪**：¥20 现成 8 通道，比自制强；
- **NAND 编程器**：必须买成品（RT809H 之类），自制的 ECC 处理不了。

## 五、嘉立创下单要点

- **打样**：5 片起，¥5–30（2 层小板上限很低），3–5 天；
- **贴片**：如果板上有电阻，可以选 SMT（他们贴好寄来），但插件（排针/探针）还得自己焊；
- **文件**：需要 Gerber（.gbr 压缩包）或嘉立创 EDA 工程；
- **我这边能做的**：原理图、网表、BOM、尺寸和叠层建议、走线约束；
- **我这边不能做的**：不能替你下单/付款，也不能保证布局在真机上严丝合缝（尺寸要你量）。

## 六、边界（写在前面）

1. 第一块板做完，**先用万用表验证通断和短路**，再插相机。
2. 板子只是"接线工具"，**不改变相机的任何状态**——所以它本身是安全的。
3. 别一次做三块。先做 A，用顺手了再考虑 B。

## 七、社区/成品调查结果（2026-11-14 补，用户提议后）

**结论：探针夹具不用自研了，社区已经做透了。**

| 来源 | 是什么 | 要点 |
|---|---|---|
| [Pogo Pin 弹簧探针烧录助手](https://oshwhub.com/tosh1ue/pogopin-spring-probe-burn-assist) | PCB + 弹簧合页 + M3 螺丝 + 1×5P 排针 + Pogo Pin，做成"夹子" | CC BY-NC-SA 4.0，可直接在嘉立创打样 |
| [双排 8P 烧录夹/探针夹](https://oshwhub.com/tsl0922/shao-lu-jia) | 2.54×8P 与 2.0×8P 二合一，**用 P100 探针** | GPL 3.0，作者建议全用 P100（更长，兼容带壳场景） |
| [单排版原工程](https://oshwhub.com/zhigao1986/ce-shi-jia-_-tan-zhen_copy) | 上面那个的双排版的前身 | 更适合少量点位 |
| [长长长长烧录夹](https://makerworld.com.cn/zh/models/2230511) | 3D 打印版测试夹 | 可用嘉立创3D打印 |

**假电池**：官方/第三方 AC-PW20（NP-FW50 DC Coupler）直接买，**不需要自研板**。
要测电流就在 DC 线中间串一个 ¥10 的直流电流表。

### 因此自研的边界收窄为

1. **只有当相机上的调试点是"散布的单点"而不是等距排针时**，才需要"单根探针 + 磁力/胶带固定"的治具——那是机械问题，不是 PCB 问题；
2. 如果是 1.27 / 2.54 等距一排 → **直接复刻上面开源工程**（立创一键下单，比自己画快且已验证）；
3. 假电池供电 → 买 AC-PW20，零设计。

> 教训：**先找现成方案，再考虑自研。** 这次差点为了"做块板"去做一块已经有人做好的板。
