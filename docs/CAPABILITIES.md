# NEX-7 能力清单（2026-11-15 更新）

> 每条都标证据等级：**[实测]** 上过真机 / **[静态]** 只读过代码或数据 / **[推测]** 未验证
> 旧版清单（2026-11-12）里的几处错误已在此更正。

## 一、已做成（有真机证据）[实测]

| 项目 | 结果 | 证据 |
|---|---|---|
| **JPEG 画质补丁** | STD ≈ 原厂 FINE，FINE ≈ 隐藏 EXFINE，体积 +60~70% | 实拍对比 |
| **录像时长 29:50 → 13 小时** | 有效 | 长时间录制实测 |
| **verskip 刷写** | 同版本/降级都能刷，版本号不锁死 | flash_verskip2.log |
| **刷写链路** | TPZL 4KB 分段 → sum 更新 → 打包 → 刷入，全通 | verify_packages.py |
| **NAND 分区 dump** | 静态 ARM 工具，能在升级模式下读分区 | nandump2 实测 |
| **语言/设置修改** | 通过 Backup 属性层 | 实测 |
| **4:2:0 → 4:2:2** | **本来就是 4:2:2**，无需改 | 实测采样 |

> 更正：0x6D032 不是"画质总开关"，它在 `src/dgi_jpeg_qtable.c` 里，
> 是 **JPEG 量化表缩放**，只影响 JPEG。

## 三、做不到（有依据，不是"没试过"）

| 项目 | 依据 |
|---|---|
| **给 NEX-7 装 Android / 移植 Android** | 内核里 `binder` 0 次、`ashmem` 0 次、`logger` 0 次（NEX-6：137 / 10 / 8）→ 需重编内核，板级源码不存在 [静态] |
| **装 PMCA 应用** | 同上：没有 Android 用户态，APK 无处可跑 [静态] |
| **换 UI / 菜单** | uxc 是索尼私有资源格式，没有编辑器 [静态] |
| **免拆救砖** | 启动标志位都在 NAND 上，就算找到也要物理写入 [静态] |
| **重编内核加功能（网络等）** | 没有板级移植代码；内核本身也没有 net 栈 [静态] |

## 四、已排除的无效路径（都刷过真机、测过）[实测]

- **av-cam 字面量组**（16M/12M/9M/18M/10M/3M `0x2B7A10）→ 刷了，码率无变化
- **libmpr.so 28M/24M/18M `0x4ED990** → 刷了（`flash_bitrate8b.log`），PS 26.17 / FX 20.83，无变化
- **av-cam 的 6 份量化表** → 不参与编码
- **"改 Mbps 数字就能提码率"这个思路本身** → 4 组独立实验否定

## 五、一句话看形状

**能改的**：镜像里的数据、应用层的库、场景插件的替换、设置层属性。
**不能改的**：内核、Android 层、UI 资源。
**必须等的**：那台相机能开机。
