# 硬件基础小课（只讲这次用得上的）

> 前提：你已经会量电压、会用万用表。那其实已经过了 80% 的门槛。
> 这篇的目标不是把你教成电子工程师，而是让你**能自己判断"这个点能不能接、是什么"**。

---

## 1. 先建立一个心智模型：板子上只有三类东西

忘掉"电路很复杂"，一块主板上跑的其实只有三件事：

| 类别 | 作用 | 怎么认 |
|---|---|---|
| **电（VCC）** | 给芯片供电，这里是 3.3V / 1.8V / 1.2V | 稳定不动、通常在电容旁边、面积大的铜皮 |
| **地（GND）** | 所有电压的参考点，等于"0V"，全板通 | 和屏蔽罩、螺丝孔铜环通的都是它 |
| **信号** | 芯片之间传信息，电压在 0 和 3.3V 之间跳 | **会变** —— 这是它和电源最大的区别 |

**关键洞察**：你只要看一个点的电压"变不变"，就能分出它是电源还是信号。
这正是我们找 TX 的全部原理。

---

## 2. 电压的三种"样子"

| 读数 | 含义 | 例子 |
|---|---|---|
| 稳定 3.3V（或 1.8 / 1.2V） | 电源轨 | **不要接**（接了会把两路电源顶在一起） |
| 稳定 0V，且和 GND 通 | 地 | 可以接（GND 就是它） |
| **会变**：0～3.3V 之间跳 | 信号 | 我们的目标 |
| 悬空时读到 1.xV 这种"不三不四"的电压 | **悬空（floating）**，假电压 | 什么都没接，表笔在拾空气中的电位 |

最后一行很重要：新手常被 1.5V、1.8V 这种读数骗到，以为找到了什么。
**悬空点的电压会随你的手靠近而变化** —— 这就是它的特征。

---

## 3. 串口（UART）到底是什么

串口是两根线、一个约定：**一根发、一根收、事先说好速度**。

@@@
  空闲(高)      起始位  数据位(8个)         停止位
  3.3V  +-----+       +-+   +-+            +-----+
        |     |       | |   | |            |     |
  0V ---+     +-------+ +---+ +------------+     +---
@@@

三条规则，记住就够用：

1. **空闲时是高电平（3.3V）**。没数据的时候，TX 线上就是稳稳的 3.3V。
2. **一发数据就会往下掉**（起始位是低电平）。所以"开机时有数据在传"的表现是：
   **电压不再是稳稳的 3.3V，而是在抖**。
3. **速度（波特率）要事先约定**，两边必须一致。对不上就是乱码 —— 不是线坏了，是"听得太快或太慢"。

> 这就是为什么手册里让你按 115200 → 38400 → 9600 一个一个试：
> 只有对了那一个，你才会看到人话。

### TX 和 RX
- **TX**（Transmit）= 发送端。"相机的 TX" = 相机往外吐字的线。
- **RX**（Receive）= 接收端。"模块的 RXD" 要接到"相机的 TX"。
- 接反了不会烧，只是收不到东西。

---

## 4. 为什么"只接 GND + TX"是安全的

这是这套操作里最重要的安全逻辑，值得讲明白：

- **每条信号线都有"谁驱动谁"**：TX 是相机驱动的输出，我们的 USB-TTL 只是**听**（高阻输入）。
- 所以相机 TX → 模块 RXD 这条线上，**只有一个芯片在说话**，不会打架。
- **VCC 不接**的原因：如果模块和相机各自给自己供电，两条电源接在一起会互相倒灌
  （3.3V 和 3.3V 不完全相等），轻则读不准，重则烧稳压器。

一句话记法：**只接"地"和"说的话"，不接"电"。**

## 5. 万用表三个用法（这次用得到的全部）

| 档位 | 怎么用 | 判读 |
|---|---|---|
| **通断 / 蜂鸣** | 两表笔点两个点 | 响 = 同一根线（同一个网络） |
| **直流电压（V= 20V 或 2V）** | 黑笔接 GND，红笔点目标 | 看读数稳不稳、开机瞬间跳不跳 |
| 二极管档（有的表没蜂鸣用它） | 同通断 | 显示 0.3-0.7 = 通 |

**注意**：通断档测的时候**必须断电（拔电池）**，否则可能读到别的元件把电导过去，误判。

---

## 6. "追线"：怎么确认两个点是同一根线

这是硬件维修最常用的一个技巧，比认芯片管脚有用得多：

1. 拔电池；
2. 万用表打**通断档**；
3. 一个表笔点 A 点，另一个点 B 点；
4. **响 = A 和 B 是同一根线（同一个网络）**，中间可能隔了一个 0 欧电阻或电感，
   但电气上是通的。

用途举例：
- 主板正面有个可疑焊盘，背面有个过孔，想知道是不是同一个 —— 量一下就知道。
- 你想从"好下手的过孔"接线，但要确认它确实连到怀疑的焊盘。

**这正是"不用懂每个引脚定义"也能工作的原因**：你不需要知道 SoC 的球脚编号，
只需要知道"这两个点是不是同一根线"。

## 7. 板子上常见的东西（认脸）

| 长什么样 | 是什么 | 备注 |
|---|---|---|
| 最大那颗方形芯片 | **SoC**（CXD4132） | BGA 封装，引脚在**底部**，肉眼看不到 |
| 芯片周围一小堆米粒 | **电容**（去耦） | 每个电源脚旁边都有，说明那一带是供电区 |
| 盖住一片区域的金属罩 | **屏蔽罩** | 焊在 GND 上，掀开要热风枪，先别动 |
| 一个孤零零的**圆焊盘** | **测试点（TP）** | 工厂调试留的，最理想的接入点 |
| 一**排等距**的小焊盘 / 小孔 | 排针位 / 过孔阵列 | 调试口常长这样，**重点怀疑对象** |
| 一排金色细线连到插座 | **FPC 排线** | 拔的时候捏卡扣，不要拽线 |
| 板上印的白字（R37、C12、TP5） | **丝印** | 元件编号，TP 开头的基本都是测试点 |

## 8. 术语表（这次会遇到的）

| 词 | 一句话解释 |
|---|---|
| **GND** | 地，0V 参考点 |
| **VCC / VDD** | 电源正极 |
| **TX / RX** | 串口的发 / 收 |
| **TTL 电平** | 0V=0，3.3V=1 这种最直白的电平（区别于 RS232 的 ±12V） |
| **波特率** | 每秒传多少位，115200 就是 115200 bit/s |
| **上拉 / 下拉** | 用一个电阻把线"默认拉到"高 / 低电平，防止悬空 |
| **悬空** | 什么都没接，读数不可信 |
| **过孔（via）** | 板子上的小洞，连通不同层，**免焊接线的理想位置** |
| **BGA** | 引脚是底部的小球，肉眼不可见，不能飞线 |
| **TSOP** | 引脚在两侧伸出来的封装（相机的 NAND 就是） |
| **FPC / FFC** | 柔性排线 |

## 9. 判读表：看到什么 = 说明什么

| 现象 | 说明 |
|---|---|
| 某点 3.3V 稳稳的 | 电源，别接 |
| 某点和屏蔽罩通 | GND |
| 开机瞬间电压抖一下 | 极可能是 TX |
| 接了线但读到的都是 0x00 / 乱码 | 波特率不对，或者接的是 RX 不是 TX |
| 什么都不显示 | 接触不良（探针没压住）最常见，先动动线 |
| 读数在你手靠近时变 | 悬空，不是有效点 |

---

## 10. 五个最容易犯的错

1. **接 VCC** —— 唯一可能烧板子的操作，永远不接。
2. **不共地** —— 模块和相机必须共用同一个 GND，否则读到垃圾。
3. **TX / RX 接反** —— 不烧，但收不到，排查顺序里第二条就该查它。
4. **通断档不断电** —— 会误判成"通"。
5. **探针没压住却以为板子坏了** —— 先用镊子轻压再判断。

---

## 11. 学到这里，你其实已经能做这些了

- 独立找出 GND（通断档 + 屏蔽罩）；
- 独立找出"会变的点"（直流电压档 + 开机瞬间）；
- 用通断判断两个点是不是同一根线（追线）；
- 判断一个点该不该接（电源 / 地 / 信号）；
- 看懂串口为什么乱码（波特率）；
- 知道什么时候必须停手（VCC、BGA、屏蔽罩）。

**这已经超过很多修手机的对新手的期待了。** 剩下的（认 SoC 每个球的定义）需要芯片手册，
我们没有 —— 但这次也不需要。
