# 索尼 SIRC 红外间隔触发器（ESP32）

> 目标：给 NEX-7（以及任何 NEX/Alpha）做一个"遥控器 + 间隔拍摄"二合一。
> 固件：`ir_trigger.ino`

## 一、买什么（¥20 左右）

| 物品 | 规格 | 价 |
|---|---|---|
| ESP32 开发板 | 任意 ESP32-WROOM 开发板，USB-C 更好 | ¥15–20 |
| 红外发射管 | **940nm，5mm**（不是接收头） | ¥1–3 |
| 三极管 | **S8050**（NPN）或 2N3904 | ¥1 |
| 电阻 | 1kΩ ×1、100Ω ×1 | ¥1 |

**不要买**：HX1838/VS1838B 接收头（那是"耳朵"）、NEC 遥控器套装（协议不对）。

## 二、接线

```
ESP32 GPIO4 ──[1kΩ]── S8050 基极(B)
ESP32 5V    ── LED正极(+) ──[100Ω]── 集电极(C)
ESP32 GND   ─────────────────────── 发射极(E)
```

红外 LED 长脚是正极。三极管平面对着自己，从左到右一般是 E-B-C（S8050 是 EBC）。

## 三、烧固件

1. Arduino IDE → 开发板管理器里装 esp32；
2. 板子选 **ESP32 Dev Module**；
3. 打开 `ir_trigger.ino`，直接上传；
4. 串口监视器 115200，看到帮助信息就成功了。

## 四、怎么用

```
s              立即快门
d              2 秒延迟快门（先对焦再拍）
v              录像启停
i 30 100       每 30 秒拍一张，共 100 张
i 20           每 20 秒一张，无限
x              停止间隔
```

每拍一张，板载蓝灯闪一下，串口打印剩余张数。

## 五、相机侧必须做的设置

1. **菜单里把 Remote Cdr.（遥控）打开** —— 不开的话红外一律不理；
2. 驱动模式选 Single Shooting（单张），不要连拍；
3. 拍星空：M 档、手动对焦、**关掉长曝光降噪**（否则每张后多一张等长黑帧，间隔翻倍）；
4. 电池满电，或用 AC-PW20 供电。

## 六、还没验证的部分

- **这个码没在 NEX-7 上实测过**（相机现在是砖）。来源是公开资料：NEX/Alpha 通用地址 0x1E3A，
  快门 0x2D，2 秒 0x37，录像 0x48；社区在 NEX-5 上验证过。
- 如果没反应，先查三件事：Remote Cdr. 是否打开、LED 是否真的在发、三极管方向是否接反。

## 七、验证"有没有在发"的土办法

拿**手机摄像头**对着红外 LED，按一下 s：

- 屏幕里看到 LED 发紫/发白地闪 → 在发；
- 什么都看不到 → 没发（查接线/代码）。

不需要任何仪器。
